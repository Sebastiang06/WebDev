Web Technologies

HTML

HTML is the hyper text markup language. It has pure text data that is "marked up". The browser renders the web page. HTML includes elements or tages that encloses between angle brackets.

CSS

CSS stands for Cascading Style Sheets. CSS is the standard design language used to style and format the visual presentation of web pages. CSS controls everything from color schemes, fonts, and text layout to background images, spacing, and advanced responsive animations.

JavaScript

JavaScript is a lightweight, high-level programming language primarily known as the scripting engine that powers dynamic and interactive behavior on the web. JavaScript works alongside the other two core technologies of the internet, which hare HTML and CSS. JavaScript uses the DOM as a bridge to manipulate the page.

Web Technologies

JQuery

JQuery is a fast, small, and feature-rich JavaScript library created to simplify client-side HTML scripting. It wraps common tasks into concise methods so developers can achieve complex results with significantly less code. By using a single, unified syntax, it eliminates the need to write repetitive scripts for routine web development tasks.

Bootstrap

Bootstrap is a highly popular, open-source front-end framework used by developers to create responsive and mobile-first websites. It provides a comprehensive collection of pre-designed HTML, CSS, and JavaScript components like buttons, navigation bars, and forms. By using these ready-made elements, developers can significantly speed up the coding process and ensure their websites look consistent across all devices.

AFrame

AFrame is an open-source web framework designed for building virtual reality (VR) experiences using HTML. Developed by Supermedium and originally Mozilla, it allows developers to create 3D scenes by simply adding tags to a standard web page without needing complex JavaScript libraries. Because it runs directly in the browser, A-Frame code works seamlessly across desktop, mobile, and VR headsets like the Meta Quest or Apple Vision Pro.
